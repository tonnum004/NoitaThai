# Noita ภาษาไทย

ม็อดแปลเกม Noita เป็นภาษาไทย พร้อมฟอนต์พิกเซลไทย

## ติดตั้ง

1. กดปุ่ม **Code → Download ZIP** แล้วแตกไฟล์
2. ปิดเกม Noita
3. ดับเบิลคลิก `install.bat`
   (ถ้า Windows ขึ้น "Windows protected your PC" ให้กด More info → Run anyway)
4. เปิดเกมได้เลย

รายละเอียดอื่น วิธีแก้คำแปล และวิธีแก้ฟอนต์ อยู่ใน [README_THAI.txt](README_THAI.txt)

ฟอนต์ไทยดัดแปลงจาก IBM Plex Sans Thai Looped, SIL Open Font License 1.1 ([fonts_src/OFL.txt](fonts_src/OFL.txt))
